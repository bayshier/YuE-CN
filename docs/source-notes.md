# 公开文档素材来源

README 的前沿对比图与架构图翻制自 [YuE2 Demo 页](https://map-yue2.github.io/#model-overview)。Logo 为原项目 Logo，沿用自 [YuE-v1](https://github.com/multimodal-art-projection/YuE/tree/YuE-v1/assets/logo)。PNG 的文字、时间戳与 EXIF 元数据已在存在处移除，图像像素保持不变。这些图与原始示例输入均为文档素材，不是生成的评测音频。

机构面板沿用 [Demo 页](https://map-yue2.github.io/)的八个标识及其顺序，提供桌面与移动两种布局。SVG 内含原始矢量图形与内嵌位图；移除 EXIF 元数据时未重新压缩图像像素。机构名称与标识归各机构所有。

[WSB CSV](benchmark-results.csv) 是 Demo 页展示的 2026 年 9 月 12 日结果集。README 展示了 17 个设定的四项指标；CSV 保留完整的指标集合。基准范围与候选挑选记录在 [benchmarks.md](benchmarks.md)。
